CONG CU SAO LUU VA KHOI PHUC GOLDEN GATE (Windows + XAMPP)

backup.bat           Sao luu co so du lieu va anh mon an vao C:\goldengate_backups (giu 30 ngay)
restore.bat          Khoi phuc tu mot file sao luu (GHI DE du lieu hien tai, co hoi xac nhan)
schedule_backup.bat  Dat lich sao luu tu dong moi ngay luc 03:00 (chay bang Run as administrator)

Truoc khi dung: mo tung file bang Notepad, kiem tra cac dong "set" o dau file (duong dan XAMPP, mat khau MySQL).
Nen chep thu muc C:\goldengate_backups sang o cung ngoai hoac dich vu luu tru dam may dinh ky.
